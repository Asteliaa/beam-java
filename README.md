| Папка | Лабораторная работа | Материалы |
|---|---|---|
| [airp/lab1](airp/lab1) | №1. Работа с Web-ресурсами (поиск названия лекарства по симптомам) | [docs](airp/lab1/docs) |
| [airp/lab2](airp/lab2) | №2. Работа на основе сокетных соединений (два клиента-потока, запуск на трёх компьютерах) | [docs](airp/lab2/docs) |
| [airp/lab3](airp/lab3) | №3. Работа с серверными классами (сервлеты, словарь, сервлет с рисунком) | [docs](airp/lab3/docs) |

## Что нужно установить

JDK 17 или новее. Для лабораторной 3 дополнительно **Maven** и **Apache Tomcat 9**.

## Быстрый запуск

**Лабораторная 1** (из папки `airp/lab1`):

```bash
javac -encoding UTF-8 -cp "lib/*" -d out src/web_res_lab/Web_res_lab.java
java -Dfile.encoding=UTF-8 -cp "out;lib/*" web_res_lab.Web_res_lab   # Windows; на Mac/Linux: -cp "out:lib/*"
```

**Лабораторная 2** (из папки `airp/lab2`): готовый `serv.jar`, скрипты для Windows, Mac и Linux (WSL):

```bash
java -jar serv.jar                 # сервер и клиенты на одном компьютере
java -jar serv.jar 192.168.0.5     # только клиенты, сервер на компьютере с этим IP
```

Подробно, в том числе запуск на трёх компьютерах: [airp/lab2/docs/01-ЗАПУСК.md](airp/lab2/docs/01-ЗАПУСК.md).

**Лабораторная 3** (из папки `airp/lab3`): Windows: `1-build-and-start-tomcat.bat`, затем http://localhost:8080/lab_servlet/ ; клиент: `2-run-client.bat`; остановка: `3-stop-tomcat.bat`. Вручную: `mvn package` в `lab_servlet`, скопировать `target/lab_servlet.war` в `webapps` Tomcat 9.
