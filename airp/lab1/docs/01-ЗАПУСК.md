# АИРП, лабораторная работа 1. Как запустить

Тема: **Работа с Web-ресурсами** (поиск информации по ключевым словам). Вариант 2: **поиск названия лекарства по 1–3 симптомам**. Код в папке `airp/lab1`.

## Что установить

| Что | Зачем | Проверка |
|---|---|---|
| **JDK 17 или новее** (Temurin, Zulu, Oracle) | компиляция и запуск Java | `javac -version` и `java -version` |
| Браузер по умолчанию | программа открывает в нём найденный документ | |
| VS Code + **Extension Pack for Java** (или NetBeans, как в методичке) | показывать код | |

## Запуск из терминала

```bash
git clone https://github.com/KsushaKhadzhinova/beam-java.git
cd beam-java/airp/lab1
javac -encoding UTF-8 -cp "lib/*" -d out src/web_res_lab/Web_res_lab.java
java -Dfile.encoding=UTF-8 -cp "out;lib/*" web_res_lab.Web_res_lab   # Windows; на Mac/Linux: -cp "out:lib/*"
```

Разбор команд:

| Часть | Значение |
|---|---|
| `javac` | компилятор Java |
| `-encoding UTF-8` | исходный файл содержит русские буквы в кодировке UTF-8 |
| `-d out` | положить готовые `.class`-файлы в папку `out` |
| `src/web_res_lab/Web_res_lab.java` | какой файл компилировать |
| `java` | запуск программы |
| `-Dfile.encoding=UTF-8` | читать/выводить текст в UTF-8 (чтобы русский текст не превращался в «кракозябры») |
| `-cp out` | где искать классы (**c**lass**p**ath) |
| `web_res_lab.Web_res_lab` | полное имя класса: пакет `web_res_lab` + класс `Web_res_lab` |

**Запускать нужно из папки `airp/lab1`**: программа ищет файл `medicines.txt` и папку `source_html` **рядом с местом запуска** (относительные пути).

## Как пользоваться

1. Откроется окно «My Window» с большим текстовым полем и кнопками `Search` и `Exit`.
2. В текстовое поле введите **от одного до трёх симптомов через запятую**, например: `головная боль, высокая температура`.
3. Нажмите **Search**. В поле появится список лекарств с числом совпадений, а внизу «Лекарство: Парацетамол».
4. Браузер автоматически откроет страницу найденного лекарства (`source_html/Парацетамол.html`).
5. `Exit` – закрыть программу.

Данные (учебный набор, не медицинская рекомендация) находятся в `medicines.txt`:

| Лекарство | Симптомы |
|---|---|
| Парацетамол | головная боль, высокая температура, боль в горле, озноб |
| Ибупрофен | боль в суставах, боль в мышцах, воспаление, высокая температура |
| Лоратадин | насморк, чихание, зуд, слезотечение |
| Но-шпа | спазм, боль в животе, боль в желудке |
| Активированный уголь | тошнота, вздутие, отравление, диарея |
| Амброксол | кашель, мокрота, бронхит |

> Набор данных составлен для лабораторной; методичка требует **согласовать собственный набор с преподавателем**. Чтобы подставить другой набор, замените строки в `medicines.txt` (формат `Название | симптом, симптом`) и положите рядом html-файл `source_html/<Название>.html`.

## Что делать, если не работает

| Симптом | Причина и решение |
|---|---|
| `javac` не найден | JDK не установлен или нет в `PATH`; установите JDK, откройте новый терминал |
| В окне пусто после Search | запуск не из папки `lab1` (нет `medicines.txt`) – перейдите в `airp/lab1` |
| Вместо русских букв «???» | не указан `-Dfile.encoding=UTF-8` |
| Браузер не открылся | `Desktop.browse` не поддерживается в вашей системе; откройте файл из `source_html` вручную |
